# Original Assets Directory

This directory contains high-resolution source images organized by content type:

- `blog/` - Images for blog posts
- `projects/` - Screenshots and project visuals
- `research/` - Figures, charts, and research graphics
- `writing/` - Creative writing illustrations

## Usage

Place your original, high-quality images here. The build process will:
1. Optimize these images using Astro's Image component
2. Generate multiple formats (WebP, AVIF)
3. Create responsive sizes
4. Output to the production build

## Best Practices

- Use descriptive filenames: `economic-growth-chart-2024.png`
- Keep originals at highest quality available
- Organize by year/topic within each directory
- Maximum recommended width: 2560px for web use
