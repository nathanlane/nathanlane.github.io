#### Link: An Investigative Journalist's Guide to Geolocating Media

</a>

**bell?ngcat**, a crowd-funded start-up of Middle East wonks, investigative journalists, and researchers, <a href="http://qz.com/254405/kickstarter-funded-journalists-found-an-isil-training-camp-using-google-earth-and-bing-maps/#/h/98673,1/" target="_blank">has made some waves for demonstrating how to geo-locate an Iraqi ISIS training camp</a>.

Here are a couple of fantastic guides to some of the techniques they use to geolocate media, combining picture/video data alongside common geographic tools. One of the interesting techniques used lately consists of extracting and mapping metadata from photographs using tools like <a href="http://www.panoramio.com/?_ga=1.210479445.1905603640.1404103144" target="_blank">Panoramio</a>.
