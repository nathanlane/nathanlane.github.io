# Example Private Note

This is an example of a private note. These notes are:

- **Never web-accessible** - They don't appear on the website in any environment
- **Personal documentation** - Use them for project notes, todos, ideas, etc.
- **Version controlled** - They're part of your git repository
- **Markdown/MDX** - Full markdown support with frontmatter

## Use Cases

- Personal project documentation
- Development notes and reminders
- Ideas and drafts
- Technical research
- Meeting notes
- Architecture decisions (private)

## Organization

You can organize private notes with:
- Descriptive filenames
- Tags in frontmatter
- Subdirectories if needed
- Date-based organization

## Security Note

Remember that while these notes are not web-accessible, they are still part of your git repository. Don't include sensitive information like passwords or API keys.
